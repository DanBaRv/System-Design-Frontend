# ChannelsStat Frontend — Лабораторная работа №5

**Тема:** История пересылки поста в каналах (PostTrace)

**Цель работы:** разработка базового SPA на React.

**Стек:** React 18, TypeScript, Vite, React-Bootstrap. Данные — коллекция mock-объектов (без обращения к бэкенду).

---

## Запуск проекта

```bash
npm install       # установить зависимости
npm run dev       # запуск dev-сервера
```

Приложение открывается на http://localhost:5173

---

## Страницы приложения

### 1. Лента (доступна)

Вертикальная лента услуг — одна карточка под другой (аналог ленты из ЛР1).

**Элементы страницы:**

| Элемент | Описание |
|---|---|
| Видео услуги | Проигрыватель (controls). Если поле videoUrl пустое — видео по умолчанию `default_video.mp4` |
| Название канала | Заголовок карточки |
| Тематика | Текст под названием |
| Количество подписчиков | Число с иконкой |

**Доступные действия:** просмотр (воспроизведение видео). Интерактив с данными в лабораторной не выполняется.

### 2. Плитка (доступна)

Каталог услуг в виде сетки карточек (2 колонки) с фильтром.

**Элементы страницы:**

| Элемент | Описание |
|---|---|
| Кнопки фильтра по теме | «Все, Технологии, Новости, Юмор, Бизнес, Путешествия». Активная подсвечена |
| Карточка услуги | Обложка (при пустом поле — `default_cover.jpg`), название, тематика, подписчики |

**Доступные действия:** переключение фильтра по теме — список карточек обновляется без перезагрузки (пересчёт по состоянию).

### 3. Добавление (недоступна)

Пункт навигации отображается, кнопка заблокирована (`disabled`). Реализация — в последующих лабораторных.

### 4. Вход (недоступна)

Пункт навигации отображается, кнопка заблокирована (`disabled`). Реализация — в последующих лабораторных (подключение к API аутентификации).

## Навигация

Нижняя навигационная панель (Navbar) — 4 пункта: **Лента, Добавление, Плитка, Вход**.

- Доступны: **Лента**, **Плитка** — переключают активную страницу
- Недоступны: **Добавление**, **Вход** — заблокированы

Активная страница подсвечивается. Переключение реализовано через состояние `page` в `App` (хук `useState`); Navbar получает текущее значение и функцию переключения через props.

---

## Компоненты и props

| Компонент | Props | Назначение |
|---|---|---|
| `Navbar` | `page: string` — активная страница; `onNavigate: (page) => void` — функция переключения | Панель навигации: 4 кнопки, клик вызывает переданную функцию |
| `FeedPage` | — (данные из mock-коллекции) | Вертикальная лента |
| `CatalogPage` | — (данные из mock-коллекции) | Плитка + фильтр по теме (состояние `topic` через `useState`) |
| `ChannelCard` | `channel: Channel` — объект услуги | Карточка: подставляет дефолтные медиа при пустых полях |

Данные передаются сверху вниз (родитель → потомок). События (клики) передаются наверх через функции-props.

---

## Используемые хуки

| Хук | Где | Что хранит |
|---|---|---|
| `useState` | `App` | `page` — активная страница ('feed' / 'catalog') |
| `useState` | `CatalogPage` | `topic` — выбранная тема фильтра ('' — все) |

## Изображения и видео по умолчанию

Если у услуги пустое поле `coverUrl` или `videoUrl`, компонент подставляет файлы из проекта:

```
public/default_cover.jpg
public/default_video.mp4
```

Реализовано в `ChannelCard` (обложка) и `FeedPage` (видео) через оператор `??`:

```typescript
src={channel.videoUrl ?? '/default_cover.jpg'}
```

## Данные (mock)

Источник данных — массив объектов `channels` в `src/data/channels.ts`, структура соответствует услуге (каналу):

```typescript
interface Channel {
    id: number
    name: string
    topic: string
    subscribersCount: number
    averageReach: number
    adPrice: number
    coverUrl: string | null
    videoUrl: string | null
}
```

Часть каналов имеет `coverUrl`/`videoUrl` = `null` — для демонстрации медиа по умолчанию.

Обращений к бэкенду нет — проверяется во вкладке Network (DevTools): только статические файлы.
